# 샬롬찬송가 (Shalom Hymn App)

통일찬송가 558곡 전곡을 언제 어디서나 편리하게 검색하고 볼 수 있는 모바일 최적화 웹 앱입니다.

## ✨ 주요 기능
- **전곡 수록**: 통일찬송가 1장부터 558장까지 모든 악보와 가사 수록.
- **스마트 검색**: 장 번호, 제목은 물론 **초성 검색**과 **가사 내용 검색** 지원.
- **Canvas Stitching**: 여러 페이지로 구성된 악보를 실시간으로 병합하여 한 화면에서 끊김 없이 감상.
- **다크 모드**: 야간이나 어두운 예배당에서도 눈이 편안한 모드 지원.
- **즐겨찾기**: 자주 부르는 찬송가를 북마크하여 빠르게 접근.
- **조바꿈(Transpose) 가이드**: 연주자를 위한 조바꿈 기능 (TBD).

## 🚀 배포 방법
이 프로젝트는 정적 파일로 구성되어 있어 어디든 쉽게 배포할 수 있습니다.

### GitHub Pages 배포 (추천)
1. GitHub 저장소를 생성하고 이 폴더의 모든 파일을 업로드합니다.
2. `Settings > Pages`에서 배포 브랜치를 선택하고 저장합니다.
3. 생성된 URL을 통해 접속합니다.

## 📱 기술 스택
- HTML5, Vanilla CSS3, JavaScript (ES6+)
- Canvas API (이미지 합성 기술)
- LocalStorage (설정 및 즐겨찾기 저장)
